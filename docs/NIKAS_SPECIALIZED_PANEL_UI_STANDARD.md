# NikaS Specialized Panel UI Standard v1.6 — LIDER snapshot

**Status:** REQUIRED  
**Runtime:** LIDER UI v0.4.5

## Неподвижная оболочка

- Header, переключатель устройства при его наличии и Bottom Tab Bar находятся вне рабочей области и не масштабируются.
- Header учитывает safe area один раз и расположен ниже Dynamic Island/выреза.
- Сетка Header: `52 / 1fr / 52`, на узком экране `48 / 1fr / 48`.
- Обе системные кнопки имеют плашки 44×44 px, радиус 16 px и MDI-иконки 25 px.
- Слева допускается только `mdi:menu`, отправляющая `hass-toggle-menu` с `bubbles: true` и `composed: true`; справа Refresh остаётся на такой же плашке.
- Заголовок/подзаголовок: 23/14 px, на телефоне 21/13 px.
- Bottom Tab Bar полноширинный, учитывает Home Indicator, использует `ha-icon` 28 px и подписи 12 px/700; активная вкладка получает фон и основной цвет темы.

## Один zoom-viewport

- Существует ровно один viewport и один transform-canvas; повторная обёртка запрещена.
- Масштабируется только canvas через `translate3d(x, y, 0) scale(s)`; `CSS zoom` не применяется.
- Pinch двумя пальцами выполняется относительно их средней точки, диапазон — 75–200%.
- В диапазоне 97–103% завершение жеста фиксирует ровно 100%.
- Неподвижный двойной тап двумя пальцами возвращает 100%/начало и показывает `Масштаб 100%`.
- Масштаб и положение сохраняются локально для панели и выбранного устройства, если устройство выбирается внутри панели.

## Прокрутка и pan

- При 100% используются только обычная вертикальная прокрутка и `x = 0`, `y = 0`; горизонтальная прокрутка и однопальцевый transform-pan запрещены.
- При увеличении однопальцевый pan включается только по осям реального переполнения и ограничивается фактическими краями canvas.
- Изменение размеров экрана повторно ограничивает координаты.
- Смена вкладки возвращает viewport к началу; масштаб можно сохранить, недопустимые смещения сохранять нельзя.
- Появление второго пальца отменяет ожидающее удержание, а click после pinch/pan/двухпальцевого тапа кратковременно подавляется. Обычные нажатия и намеренное удержание сохраняют нативный `more-info`.

## Индикатор связи и свежести

- Индикатор вводится только по отдельному запросу для конкретной панели. Для LIDER такой запрос подтверждён.
- Транспорт: `Локально`, `Облако`, `Резерв`, `Нет связи`, `Нет данных`; показываются только фактически доступные панели состояния. Слово `Онлайн` не используется.
- Свежесть: `Данные актуальны`, `Данные устарели`, `Нет данных`.
- Цвет основного статуса управляет лампой, основной надписью, фоном 8–12% и границей около 30% того же цвета.
- Основная строка — 16 px/700, вторичная — 13 px/500–600.

## Типографика

- Значимый текст интерфейса находится в диапазоне 12–25 px.
- Размеры 9–10 px допустимы только для избыточных аннотаций внутри схемы, без которых смысл и состояние остаются полностью понятны.

## Стабильный DOM и отсутствие мерцания

- Оболочка `Header → zoom-viewport → Bottom Tab Bar` монтируется один раз и сохраняет идентичность DOM.
- `shadowRoot.innerHTML` допускается только при первоначальном монтаже.
- Телеметрия меняет существующие текстовые узлы, классы и атрибуты; Header, изображение, viewport, scroll и Bottom Tab Bar не пересоздаются.
- Индикатор обновляется только при смене категории связи/свежести; точный возраст не является причиной структурной перерисовки.
- Обновления откладываются на время активного жеста; задержка полной перерисовки не считается исправлением мерцания.

## Приёмка на iPhone

Проверяются: длинная вертикальная прокрутка при 100%, отсутствие горизонтального и верхнего смещения, только необходимые оси pan при увеличении, сохранение canvas в границах после отпускания и resize, отсутствие `отстрела` после pinch, отсутствие случайного `more-info`, а также неподвижность Header и Bottom Tab Bar при прокрутке и обновлении телеметрии.
