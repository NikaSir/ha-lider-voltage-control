# NikaS Specialized Panel UI Standard v1.4 — LIDER snapshot

**Status:** REQUIRED  
**Source:** Stark SolarPower synchronized standard  
**Shell:** v1.4 · **Zoom:** v1.3

## Оболочка

- safe area учитывается ровно один раз;
- Header расположен ниже Dynamic Island/чёлки;
- слева только системная кнопка `☰`, отправляющая `hass-toggle-menu`;
- заголовок геометрически центрирован;
- Header и нижнее меню не масштабируются;
- нижнее меню полноширинное, фиксированное и расположено выше Home Indicator;
- элементы управления имеют зоны касания около 44×44 pt или больше.

## Масштабирование

- масштабируется одна рабочая область целиком;
- pinch двумя пальцами выполняется относительно точки между пальцами;
- масштаб 75–200%, по умолчанию 100%;
- экранных кнопок масштаба нет;
- двойное касание двумя пальцами возвращает 100% и начало координат;
- завершение pinch в диапазоне 97–103% фиксирует ровно 100%;
- сброс кратко показывает `Масштаб 100%`;
- масштаб хранится локально для панели/клиента;
- увеличение допускает панорамирование.

## Семантика

- обычные измерения нейтральны;
- зелёный, жёлтый, оранжевый и красный применяются только после достоверной классификации;
- `unknown`, `unavailable`, устаревшие и отсутствующие источники не считаются нормой;
- неподтверждённые значения не создаются;
- фактические параметры открывают нативный Home Assistant `more-info`.

## Стабильный DOM и отсутствие мерцания

- оболочка `Header → zoom-viewport → Bottom Tab Bar` создаётся один раз и сохраняет идентичность DOM;
- `shadowRoot.innerHTML` допускается только при первоначальном монтаже;
- `set hass()` обновляет только существующие текстовые узлы, классы, лампы, атрибуты и значения;
- изменение возраста телеметрии и очередной опрос не пересоздают вкладку, изображение, zoom-viewport, Header или нижнее меню;
- точное число секунд возраста не входит в ключ структурной перерисовки;
- двухуровневый индикатор обновляется только при смене категории связи или актуальности;
- изображения не получают повторно `src`, если сам ресурс не изменился;
- прокрутка, инерция, pinch и pan не прерываются структурной перерисовкой;
- нижнее меню остаётся постоянным DOM-узлом вне прокручиваемого viewport;
- задержка полной перерисовки не считается исправлением мерцания: фоновые обновления должны быть точечными.

## Приёмка

Основное устройство приёмки — Home Assistant Companion App на iPhone Pro Max в портретной ориентации. Проверяются safe area, системное меню, нижнее меню, pinch/pan/reset, сохранение масштаба, явные состояния недоступности, отсутствие дублирования оболочки и отсутствие миганий, скачков или смещения нижнего меню при опросе, прокрутке и инерции.
