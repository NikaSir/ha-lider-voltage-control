# Update policy

LIDER Voltage Control принимает изменения в `main` через проверенные pull request. Фактическая доставка текущего `main` через пользовательский HACS требует отдельной приёмки; утверждённая целевая схема публикации описана в [`RELEASES.md`](RELEASES.md).

1. Разработка выполняется не в `main`.
2. Изменения проходят через pull request.
3. До слияния проверяются Python, JSON, JavaScript и согласованность панели.
4. Проверенная ветка сливается в `main`.
5. Доступность кандидата в HACS и установленная версия подтверждаются на целевой системе до объявления доставки.
6. Home Assistant перезапускается только когда это требуется.
7. Удаление config entry для обычного обновления запрещено.
8. ZIP используется только как аварийный путь восстановления.
9. Production `module_url` всегда указывает на один автономный bundle; runtime-цепочки старых UI-версий запрещены.
10. До слияния проверяются холодный запуск, пустой frontend-cache, полный restart Home Assistant, локальный доступ и Home Assistant Cloud/Nabu Casa.
11. Телефонная приёмка включает не менее десяти переключений вкладок, длинную прокрутку, pinch/pan/reset, потерю/восстановление данных и возврат заголовком во все три базовые панели.
12. Целевая схема — beta → пользовательская проверка → stable с сохранением предыдущей стабильной версии для отката; её автоматизация и фактическая публикация выполняются отдельным изменением.
